# Feedback protocol

Use this protocol for grading a submitted response. Keep the official rubric holistic; the diagnostic sections explain the score and are not separate weighted subscores.

## Inputs and confidence

Use the exact task prompt, any displayed student posts or email requirements, and the user's response. Time spent and word count are helpful but optional.

- Count the response words when text is available.
- If the prompt is missing, analyze language and development, state the relevance limitation, and lower confidence.
- If only a screenshot is supplied, transcribe the relevant prompt carefully before judging task fulfillment.
- Treat score estimates from practice platforms as comparison data, not scoring authority.

## Score snapshot

Start with:

- raw task score;
- `low`, `solid`, or `borderline` position within the band;
- confidence level;
- word count when available.

Give one sentence naming the decisive reason for the score. Do not infer the `1–6` Writing section score from one task.

## Evidence-based diagnosis

### Academic Discussion

Map the response against:

`position → contribution move → claim → mechanism → example → consequence`

Mark each component as present, partial, or missing in plain language. Then explain:

- whether the professor's question was answered directly;
- what the response adds beyond the student posts;
- where development advances and where it repeats;
- whether the example proves, illustrates, or merely restates the claim;
- which language errors affect meaning and which are only polish issues;
- which generic template phrases consume space without adding content.

Then run a separate **discussion-integration audit**:

`Professor → Student 1 → new contribution → Student 2 → nuance → conclusion`

For each available layer, report `substantive`, `acknowledged`, or `missing`:

- **Professor:** does the opening answer the exact question or requested strategy?
- **Student 1:** does the response extend, qualify, challenge, or connect the first viewpoint rather than merely summarize it?
- **New contribution:** what idea, mechanism, condition, or consequence does the writer bring to the discussion?
- **Student 2:** does the developed idea address or connect to the second viewpoint?
- **Nuance:** does a limitation or condition sharpen the position rather than weaken it?
- **Conclusion:** does it return concisely to the main answer without simple repetition?

Treat this audit as coaching diagnosis, not an invented official point system. Credit a clear original answer even when a student is not named, and never lower the ETS score solely for omitting a named reference. When both posts offer useful distinct ideas, identify failure to connect them as a missed opportunity to make the response feel more like a genuine class discussion.

### Write an Email

Check every requested bullet or action. Report coverage as complete, partial, or missing, then assess purpose, relevant detail, impact, requested action, register, politeness, organization, and language control. Classify each sentence by function—purpose, fact/context, impact, action, or close—and identify sentences that add formality without advancing the task.

Unless the user requests score-only feedback, provide a compact scenario toolkit after the diagnosis:

- a corrected direct opening;
- one specific, realistic request or next step;
- six to ten scenario-specific collocations or short frames;
- the two grammar patterns most relevant to the observed errors;
- a revised email that covers every required bullet while preserving the learner's facts and attainable voice.

### Build a Sentence

Report `0/1` for each item, the correct sentence, and the shortest useful rule: clause order, auxiliary, agreement, verb form, modifier, article, or preposition. Omit idea-bank and vocabulary sections.

## Fix first

Give at most three changes, ordered by expected score impact. State the exact gap between the current band and the next band, such as deeper consequence, clearer request, less repetition, or more controlled language. Do not imply that cosmetic vocabulary alone raises the score.

## Language corrections

Use `original → correction → reason`. Include spelling, grammar, collocation, and unnatural phrasing that teaches a reusable pattern. Separate meaning-blocking problems from timed-writing slips. Do not rewrite every acceptable sentence.

## Academic Discussion idea bank

Always provide two or three prompt-specific routes unless the user requests score-only feedback.

- Mark one route as the best fit for the user's existing position.
- Express every route as `claim → mechanism → example → consequence`.
- Prefer a route that reuses the writer's core idea before suggesting alternatives.
- Use the contribution-move labels when helpful: combine, extend, missing factor, condition, cause–effect, short–long term, or problem–solution.
- Avoid generic reasons that could be pasted into any topic.

## Topic language

Provide six to ten natural, reusable collocations or short sentence fragments. For Academic Discussion, also select two or three function-matched frames from `academic-language-menus.md` when the draft needs help with position, engagement, support, contrast, or synthesis. Include the meaning in the user's language when useful. Choose language the writer can realistically control under exam timing.

Prioritize:

- verb–noun combinations;
- comparison or cause–effect phrases;
- prompt-specific academic nouns;
- one or two useful concession or condition frames.

Avoid isolated decorative words, uncertain idioms, and vocabulary already misused by the writer unless presenting the corrected collocation.

Complete generic frames with prompt-specific content. Do not present a connector as an improvement unless the next sentence expresses the promised logical relationship.

## Revision

Give an improved response that preserves the user's position and core example, uses the best-fit idea route, and remains attainable under timed conditions. For Academic Discussion, use the discussion-complete structure when both student viewpoints can be integrated naturally; otherwise use the compact fallback and explain why. Remove generic filler and repetition before adding length. When teaching value is higher, first show a short replacement block for the weakest passage, then the complete improved response.

## Progress signal

When earlier responses are available in the conversation, end with a compact pattern check:

- **Recurring:** an issue seen again;
- **New:** a newly observed issue;
- **Improved:** a previously weak area that is now stronger.

Name only patterns supported by actual earlier responses. Do not invent a progress history.

## Next drill

Give one measurable task tied to the highest-impact weakness. Examples include rewriting one idea as a four-link causal chain, replacing three generic phrases, covering every email bullet in four functional sentences, or correcting five items of the same grammar pattern.
