# Flexible templates

Use these as planning frames. Adapt wording to the prompt and avoid memorized filler that consumes time without developing the answer.

## Academic Discussion

### Discussion-complete version — preferred when both posts are useful

```text
I think [direct answer to the professor] because [main reason].
I agree/disagree with [Student 1] that [brief paraphrase], but I would extend/refine this point by adding that [new mechanism or consequence].
For example, [specific scenario showing how the mechanism works].
This could address/qualify [Student 2]'s concern about [brief paraphrase] because [clear connection].
While [real limitation], [condition or refined position].
Ultimately, [concise return to the main recommendation].
```

Use the map, not the exact sentences:

```text
Professor → Student 1 → NEW IDEA → Example/Consequence → Student 2 → Nuance → Conclusion
```

Each reference must add a logical function. Compress, combine, or omit a student reference when it would be name-dropping, duplicate an existing point, or crowd out development.

### Direct version

```text
I believe [clear position] because [specific reason].
[Explain how or why the reason produces the claimed result].
For example, [concrete situation with a relevant detail].
[Optional nuance: acknowledge a limitation or another view briefly].
[Optional short synthesis].
```

### Connected-to-discussion version

```text
I agree/disagree with [student] that [brief paraphrase], and I would add that [new angle].
[Explain the new angle and its mechanism].
For example, [specific evidence or scenario].
[Optional nuance or concise close].
```

The student reference is optional under the official rubric. For coaching, prefer the discussion-complete version when both posts provide distinct ideas that can be integrated naturally. Keep every reference brief and use original wording.

### Respectful disagreement — compact five-move version

Use this when the learner wants to challenge one classmate's reasoning while maintaining an academic tone. Treat the five lines as functions, not mandatory fixed sentences.

```text
Although [Student A] and [Student B] raise relevant points, I believe [clear position].
In my view, the more pressing concern is [original factor] because [mechanism].
I understand [Student A]'s concern about [brief paraphrase], but it overlooks [specific gap or counterpoint].
For example, [brief concrete situation showing the mechanism].
This shows that [inference answering the professor's question].
```

Make the disagreement substantive:

- Combine acknowledgment and position when a separate courtesy sentence would consume words without adding meaning.
- `Both [A]'s and [B]'s perspectives are reasonable` is grammatically possible, but use it only when the response genuinely respects both positions.
- Prefer the student's name or singular `they/their` to `he/she` when gender is unnecessary.
- Use `However,` only for a real contrast and follow it with a comma.
- Use `First` / `Second` only for an actual ordered list. In a five-sentence response, a direct bridge such as `I understand [Name]'s concern, but...` is usually clearer than `Second of all`.
- Write `This shows that [clause]`, with subject–verb agreement and no comma after `that`.
- Replace the heading `contradict with reasoning` with the clearer function `respond with a reasoned counterpoint`.

This path normally engages one student deeply. If both student posts contain distinct useful ideas, use the discussion-complete version or add a concise bridge to the second viewpoint rather than merely praising both in the opening.

### Planning shorthand

```text
Professor's question → Two student claims → Connection → New contribution → Support → Nuance → Proofread
```

The contribution move may combine both views, extend one view, add a missing factor or condition, trace cause and effect, compare short- and long-term outcomes, or propose a problem–solution path. Choose one; do not force every move into the same response.

## Write an Email

Use the prompt-specific workflow and scenario language in [email-strategy-and-language.md](email-strategy-and-language.md). The following is a function map, not a fixed script.

```text
[Optional subject when requested: specific purpose]

Dear [appropriate recipient],

I am writing to [state the purpose directly].
[Explain the situation and the relevant facts].
[Explain the impact or why the matter is important].
Would it be possible to [clear, realistic request or proposed solution]?

Thank you for your time and assistance.

Sincerely,
[Supplied name or neutral placeholder]
```

Adapt formality to the relationship and scenario. Cover every bullet in the prompt. Prefer a direct, polite request to ornate phrasing.

Before submitting, verify this functional sequence:

```text
Purpose → Facts/context → Impact → Requested action → Polite close
```

Include urgency only when the prompt makes it relevant, and express it through a concrete deadline or consequence rather than emotional repetition. Adapt or omit the greeting, subject, and sign-off according to the prompt and interface.

## Build a Sentence check

1. Find the finite verb and its subject.
2. Identify auxiliaries, negatives, and question order.
3. Attach dependent clauses and modifiers to the words they logically describe.
4. Place objects, complements, articles, and prepositions.
5. Read the whole sentence for grammar and intended meaning before submitting.

## Model-answer rules

- Preserve the user's position unless asked to generate alternatives.
- Keep language achievable under exam timing.
- Demonstrate development and control instead of adding decorative vocabulary.
- When revising, provide a minimal correction before a polished rewrite if the distinction would teach the user more.
